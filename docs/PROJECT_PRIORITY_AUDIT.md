# Project Priority & Impact Audit — Rikkardo L. Tobing Portfolio

**Audit Date:** 2026-11-26  
**Scope:** Ranking all 23 portfolio projects (12 core + 11 Vercel workspace applications) by business impact, live production status, technical complexity, and recruiter relevance.

## Tier 1 — Flagship & Primary Showcase (Shown First in Compact View)

1. **PT Pamerindo Indonesia** (`https://www.pamerindo.com`)  
   - **Why Important:** Primary corporate gateway connecting 200+ global exhibitions and 500,000+ yearly trade visitors; 99.9% uptime SLA. Highest real-world enterprise traffic credential.
2. **Tixlantra** (`https://tixlantra.vercel.app`)  
   - **Why Important:** Live full-stack Next.js 16 + Supabase RLS SaaS with white-label multi-event ticketing, cryptographic QR passes, atomic check-in validation, Resend email delivery, and ExcelJS export. Strongest live SaaS product showcase.
3. **Kelantra** (`https://kelantra.vercel.app`)  
   - **Why Important:** Live multi-tenant B2B procurement SaaS (Next.js 15, PostgreSQL RLS, Server Actions, Zod, Vitest isolation tests). Demonstrates enterprise SaaS security & multi-tenancy.
4. **Food & Hospitality Indonesia (FHI)** (`https://www.foodhospitalityindonesia.com`)  
   - **Why Important:** Flagship B2B trade portal serving 40,000+ trade attendees and 700+ international exhibitors at JIEXPO Jakarta.
5. **Lab Indonesia** (`https://www.lab-indo.com`)  
   - **Why Important:** Southeast Asia's leading scientific instrumentation B2B portal (22,000+ attendees), directly built/modernized as part of web engineering work.
6. **Seolantra** (`https://seolantra.vercel.app`)  
   - **Why Important:** Live website intelligence SaaS using Google PageSpeed Insights v5, Inngest durable workflows, Firebase Auth HttpOnly sessions, and `@react-pdf/renderer`. Directly supports SEO & Core Web Vitals expertise.
7. **NexusAgent & PamerAi Ecosystem** (`Project-AI Agent.md`)  
   - **Why Important:** End-to-end Python/FastAPI ReAct AI agent, dual-currency USD/IDR token cost observability dashboard, and PamerAi WhatsApp PDF RAG assistant.
8. **Enterprise IoT Remote Hub** (`Project-Monitor Tablet.md`)  
   - **Why Important:** Sub-200ms remote monitoring & non-root control across 30+ Android exhibition tablets and Windows kiosks (FastAPI + Kotlin + PyAutoGUI), cutting downtime response ~90%.
9. **Cosmobeauté Indonesia** (`https://www.cosmobeauteasia.com/indonesia/`)  
   - **Why Important:** Nation's largest B2B beauty & aesthetic trade portal; showcases CMS customization & lead capture at scale.
